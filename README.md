(Work in Progress)

This is a small project started as part of a developer training program at the GPB school.
It is a simple, classic-style RPG. Code additions made by AI tools are marked accordingly.

📌 Info

The code still contains some debugging/testing statements (System.out.println).

AI-generated code additions used in: Enemy creation, Player position checking system, Dialog window system.

A simple map has been created, and collisions are implemented for the relevant tiles.

Additional maps can be created as .txt files.

A playable character has been implemented, and movement via user input is functional.

An enemy appears on the map; interacting with it opens a dialog window.

The Skeleton class should be renamed to Orc.

The game currently crashes when moving out of bounds.

🎮 Controls

Movement: WASD | Interact: E | Close dialog: Q
